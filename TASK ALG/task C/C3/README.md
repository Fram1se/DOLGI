# Код-ревью: Модуль «Закупка»

## Анализ исходного кода
В исходном шаблоне была реализована базовая структура функции `price_of` и основная логика проверки покупки. Однако значения цен для некоторых видов оружия, сообщение об отсутствии оружия в списке, расчет недостающей суммы и расчет остатка были заменены пропусками.

## Выявленные ошибки и несоответствия
1. **Отсутствуют цены для AKR, M4, AWM:** В функции `price_of` стояли пропуски `return ____` для этих видов оружия.
2. **Отсутствует сообщение об ошибке при неизвестном оружии:** Стоял пропуск `print(________)` в блоке `if price is None:`.
3. **Отсутствует расчет недостающей суммы:** Стоял пропуск `need = ________` в блоке `elif gold < price:`.
4. **Отсутствует расчет остатка:** Стоял пропуск `left = ________` в блоке `else:`.

## Внесенные исправления
В соответствии с ТЗ (строки 01-09) и таблицей цен были заполнены все пропуски:
- **Цены (AKR, M4, AWM):** Вставлены значения `2700`, `3100` и `4750` соответственно, согласно таблице прайсов.
- **Сообщение об ошибке:** Вставлено `"Нет такого оружия."`. Согласно ТЗ (строка 04), если функция вернула `None`, программа должна сообщить об этом. Точка в конце обязательна по ТЗ (строка 09).
- **Расчет недостающей суммы:** Вставлено `price - gold`. Согласно ТЗ (строка 05), нужно посчитать, сколько не хватает: цена минус текущее количество золота.
- **Расчет остатка:** Вставлено `gold - price`. Согласно ТЗ (строка 07), остаток считается как текущее золото минус цена.

## Проверка по тестовым примерам
Код успешно проходит все сценарии из ТЗ:
- Ввод `1000`, `G22` -> Вывод `Купил G22. Остаток 700`
- Ввод `100`, `M4` -> Вывод `Не хватит. Нужно ещё 3000`
- Ввод `5000`, `AWM` -> Вывод `Купил AWM. Остаток 250`
- Ввод `1000`, `Пистолет` -> Вывод `Нет такого оружия.`
- Ввод `абв` -> Вывод `Голда — число`

## Замечания по стилю
Точка после имени оружия в сообщении "Купил" реализована через конкатенацию строк: `gun + ". Остаток"`. Это соответствует ТЗ (строка 09). Пробелы в выводе `print` автоматически расставляются Python, что соответствует эталону.

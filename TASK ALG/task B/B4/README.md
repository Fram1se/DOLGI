# Код-ревью: Модуль «Копилка»

## Анализ исходного кода
В исходном шаблоне была реализована базовая структура цикла `while True` с обработкой ввода. Однако ключевые логические элементы — обработка исключения, условие выхода из цикла и накопление суммы — были заменены пропусками.

## Выявленные ошибки и несоответствия
1. **Не указан тип исключения в `except`:** Стоял пропуск `except ________:`. Без указания типа исключения невозможно корректно отловить ошибку преобразования строки в число.
2. **Отсутствует условие выхода из цикла:** Стоял пропуск `if ________:`. Без этого цикл был бы бесконечным.
3. **Отсутствует логика накопления суммы:** Стоял пропуск `total = ________`. Без этого копилка не пополнялась бы.
4. **Отсутствует вывод результата:** Стоял пропуск `print(________)`. Без этого программа не выводила бы итоговую сумму.

## Внесенные исправления
В соответствии с ТЗ (строки 01-09) были заполнены все пропуски:
- **Строка 03-05 (except):** Вставлено `ValueError`. Это позволяет отловить ситуацию, когда пользователь вводит не число (например, "абв"), вывести сообщение "Нужно целое число" и продолжить цикл (`continue`), не трогая копилку.
- **Строка 06-07 (if):** Вставлено `n == 0`. Согласно ТЗ (строка 04), ноль останавливает цикл и не попадает в сумму. Оператор `break` завершает цикл.
- **Строка 08 (total):** Вставлено `total + n`. Согласно ТЗ (строки 05, 07), любое другое целое число (включая отрицательное) прибавляется к текущему значению копилки.
- **Строка 09 (print):** Вставлено `total`. Согласно ТЗ (строка 06), после выхода из цикла печатается только итоговая сумма без лишнего текста.

## Проверка по тестовым примерам
Код успешно проходит все тесты из таблицы ТЗ:
- Ввод `5`, `5`, `0` -> Вывод `10`
- Ввод `10`, `-3`, `0` -> Вывод `7`
- Ввод `0` -> Вывод `0`
- Ввод `2`, `абв`, `3`, `0` -> Вывод `Нужно целое число`, затем `5`
- Ввод `-1`, `-1`, `0` -> Вывод `-2`

## Замечания по стилю
Использование `continue` в блоке `except` корректно пропускает итерацию и возвращает пользователя к вводу. Логика полностью соответствует алгоритму, описанному в ТЗ.

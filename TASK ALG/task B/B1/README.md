# Код-ревью: Модуль «Сумма в рублях»

## Анализ исходного кода
В исходном шаблоне была реализована только базовая часть функции `rub_word(n)`: вычисление `last_two` и `last_one`. Основная логика определения падежа существительного отсутствовала. Блок `try/except` для обработки ввода уже был предоставлен и соответствовал требованиям ТЗ.

## Выявленные ошибки и несоответствия
1. **Отсутствие логики склонения:** В функции `rub_word` не был реализован алгоритм выбора правильного окончания для слова "рубль" в зависимости от числа.
2. **Неполное соответствие ТЗ:** Строки 05-10 технического задания не были реализованы.

## Внесенные исправления
В функцию `rub_word(n)` добавлена логика согласно пунктам 05-08 ТЗ:
- **Строка 05:** Добавлена проверка `if 11 <= last_two <= 14`. Это исключение важно, так как числа 11-14 требуют слова "рублей", даже если они заканчиваются на 1, 2, 3 или 4.
- **Строка 06:** Добавлена проверка `elif last_one == 1` для слов "рубль".
- **Строка 07:** Добавлена проверка `elif last_one in (2, 3, 4)` для слов "рубля".
- **Строка 08:** Добавлен блок `else` для всех остальных случаев (слова "рублей").

Логика вывода (строки 09-10) и обработка ошибок (строки 01-02) уже были корректны в исходном шаблоне и не требовали изменений.

## Проверка по тестовым примерам
Код успешно проходит все тесты из таблицы ТЗ:
- Ввод `1` -> Вывод `1 рубль`
- Ввод `2` -> Вывод `2 рубля`
- Ввод `5` -> Вывод `5 рублей`
- Ввод `11` -> Вывод `11 рублей`
- Ввод `21` -> Вывод `21 рубль`
- Ввод `22` -> Вывод `22 рубля`
- Ввод `25` -> Вывод `25 рублей`
- Ввод `114` -> Вывод `114 рублей`
- Ввод `абв` -> Вывод `Нужно целое число`

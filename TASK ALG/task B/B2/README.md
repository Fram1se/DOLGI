# Код-ревью: Модуль «Билеты»

## Анализ исходного кода
В исходном шаблоне была реализована только базовая структура функции `ticket(age)`: объявление переменной `kind` и её возврат. Основная логика определения категории билета в зависимости от возраста отсутствовала. Блок `try/except` для обработки ввода уже был предоставлен и соответствовал требованиям ТЗ (строки 01-02, 10).

## Выявленные ошибки и несоответствия
1. **Отсутствие логики Conditions:** В функции `ticket` не был реализован алгоритм выбора фразы из списка согласно возрастным диапазонам.
2. **Неполное соответствие ТЗ:** Строки 05-09 технического задания не были реализованы.

## Внесенные исправления
В функцию `ticket(age)` добавлена логика согласно пунктам 05-09 ТЗ:
- **Строка 05:** Добавлена проверка `if age < 0 or age > 120` для возврата фразы "Возраст не подходит". Это важный фильтр, который отсекает некорректные значения до проверки основных диапазонов.
- **Строка 06:** Добавлена проверка `elif age <= 6` для возврата "Бесплатно". Использование `<=` корректно покрывает диапазон от 0 до 6 включительно.
- **Строка 07:** Добавлена проверка `elif age <= 17` для возврата "Детский билет". Так как предыдущее условие уже отсортировало детей до 6 лет, здесь остается диапазон 7-17.
- **Строка 08:** Добавлена проверка `elif age <= 64` для возврата "Обычный билет". Покрывает диапазон 18-64.
- **Строка 09:** Добавлен блок `else` для возврата "Льготный билет". Сюда попадают все оставшиеся значения (65-120), так как значения больше 120 были отсечены в первом условии.

Логика ввода/вывода (строки 03-04, 10-11) уже была корректна в исходном шаблоне.

## Проверка по тестовым примерам
Код успешно проходит все тесты из таблицы ТЗ:
- Ввод `-1` -> Вывод `Возраст не подходит`
- Ввод `0` -> Вывод `Бесплатно`
- Ввод `6` -> Вывод `Бесплатно`
- Ввод `7` -> Вывод `Детский билет`
- Ввод `17` -> Вывод `Детский билет`
- Ввод `18` -> Вывод `Обычный билет`
- Ввод `64` -> Вывод `Обычный билет`
- Ввод `65` -> Вывод `Льготный билет`
- Ввод `120` -> Вывод `Льготный билет`
- Ввод `121` -> Вывод `Возраст не подходит`
- Ввод `абв` -> Вывод `Нужно целое число`

## Замечания по стилю
Код соответствует принципу "плоского" ветвления (flat is better than nested). Использование цепочки `if/elif/else` с возрастающими порогами (`<=`) делает код читаемым и легким для проверки.
